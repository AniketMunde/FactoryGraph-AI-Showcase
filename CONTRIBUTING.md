# Contributing

Start with PUBLIC_REPRODUCIBILITY.md. Use the base software tests for an artifact-free
checkout; API-capable tests use the separate documented dependency environment.
Genuine graph/gallery/HTTP integration is opt-in and requires authorized inputs.

Preserve historical clock rules, provenance, fixed model/policy decisions and the
distinction between software fixtures and accepted research evidence. Do not make
tests pass by inserting source rows or substituting fixtures for genuine predictions.
Research changes need an explicit protocol and separately identified results.

Do not submit credentials, private logs, datasets, weights, case exports or recordings.
Generated examples must be clearly illustrative and must not reuse accepted model
scores or benchmark identities.

A project code license has not yet been selected. Contribution/reuse terms must be
agreed with the maintainer before accepting contributions; no implied contributor
agreement or exclusive ownership is asserted. See docs/LICENSING.md and
THIRD_PARTY_NOTICES.md.
