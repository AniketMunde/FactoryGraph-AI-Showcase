# Phase 6 evaluation protocol v1 — registered 2026-11-14

Freeze these four policy documents, versioned YAML, rules and report JSON schema, input
hashes and exact case requests before service case study or offline outcome summaries.
Changes after registration require a new version/run, not edited accepted outputs.
This is an engineering correctness study on previously observed synthetic data, not a
fresh predictive-accuracy or prospective operational-utility experiment.

Gate A verifies Phase 5 protection, prior manifests, implementation hashes, accepted
baseline/A0 calibration/validation/test prediction identity and all new input hashes.
Protect every prior scientific source/config/lock/test/report and all Phase 1–5 artifacts,
raw/prepared data and checkpoints. Only README, ARCHITECTURE, ROADMAP and DECISIONS may
receive chronological additions. Gate B freezes schemas/rules/policies and exact cases.
Gate C uses independent small fixtures (including future/cutoff/overlap peers and faults).
Gate D verifies genuine local Neo4j identity/build/counts/signature and primary parity.
Gate E writes the registered bounded case study. Gate F independently verifies its facts,
clocks, rules, model-policy parity and deterministic replay. Gate G measures warm per-case
graph/context/build wall times, cold service initialization, process memory and bounded
fleet latency separately. Gate H runs all existing regressions, genuine integration,
format/package/provenance and complete historical-preservation checks.

Exact selection is deterministic and label-free: first 8 test episode rows, first 8
cooldown-suppressed test rows and first 8 below-threshold rows in machine/time order;
6 fixed test times on machines 1,17,42; sparse/extensive history machines (first tie by ID)
at October 15 00:00; first four error/maintenance/failure source timestamps in October
and one hour after each, explicitly including unsupported snapshots for evidence-only
boundary checks; first three early accepted train snapshots with unavailable forecasts;
first two source-matched failure/maintenance timestamps and 3h afterward; plus unknown
machine and out-of-grid time. Deduplicate identical requests preserving first category.
Selection categories are not outcome labels; no future target annotations enter cases.
Save exact requests/selection counts before executing them. Expected failures and boundary
controls are part of scope, not population exclusions.

Compare own-window facts (including deterministic pagination/truncation), own lifetime/
window counts, static model metadata and same-model peers/window counts with independent
Pandas masks over original CSVs. Compare all public prediction/policy rows with baseline
probabilities and an independent greedy episode implementation. Verify all reported source
IDs against cutoff, all temporal clocks, exact feature rows and null handling. Validate
recommendation references/rule triggers and fixed templates; no unsupported diagnoses.
Rebuild every case and require byte-equivalent canonical content (timings stored separately).
Save evaluator-only assertions separately from operator reports; no future outcome labels
are needed to answer these correctness questions.

Fault suite: database unavailable, missing prediction, unsupported time/machine, malformed
timestamp, corrupt model/prediction/manifest/calibration, source hash mismatch, future own/
peer facts, conflicting IDs, missing provenance, incomplete temporal context and unknown
rules. No fault may produce an unverified primary recommendation or fabricated empty
history. Report failures honestly. Acceptance requires zero correctness/temporal/grounding/
parity/determinism violations and all required real Neo4j integration tests passing.
Latency/memory are descriptive local observations, no target-based tuning or reruns.
