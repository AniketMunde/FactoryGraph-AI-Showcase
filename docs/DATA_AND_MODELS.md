# Data, model and example scope

This source distribution includes independent software fixtures and aggregate public
research summaries. It excludes raw CSV/Parquet data, source-derived saved gallery
cases, checkpoint weights, database stores and private command logs.

The Microsoft sample is acquired from its pinned upstream source. Its repository MIT
notice is recorded, not treated as conclusive permission to redistribute every row or
derivative. Genuine gallery users must separately obtain authorization for case files
and configure a local ignored directory. Public summaries are selected accepted
aggregates, not complete raw experiment records or runtime inputs.

The software fixture is classified illustrative_generated_fixture. It contains no
prediction probability, source facts or accepted benchmark identity and is never a
full-mode fallback. Model integrations acquire official external dependencies; weights
are not redistributed here.

code/model cards identify Apache-2.0. Consult the respective actual upstream notices
