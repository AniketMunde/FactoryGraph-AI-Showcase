# Native deployment scope

This source supports a local authenticated retrospective demonstration. It is not a
hosted public service and does not establish machinery safety or production readiness.
Full replay needs separately authorized registered artifacts and genuine Neo4j.
Gallery mode needs authorized saved cases, which are not bundled.

Public identity/TLS, container execution and independent real-industrial validation
remain outside the verified scope. See ../SECURITY.md, VALIDATION.md and DATA_AND_MODELS.md.
