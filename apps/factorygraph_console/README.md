# Operations Console v2 — public source

The real Next.js console/BFF is retained. From repository root run npm ci, typecheck,
test and build with --prefix apps/factorygraph_console. No credential or dataset is
needed for build or the offline schema test. The genuine HTTP workflow is explicitly
opt-in and needs separately authorized cases, credentials and the native API.

Read ../../PUBLIC_REPRODUCIBILITY.md and ../../docs/DATA_AND_MODELS.md before
running gallery/full mode. The public illustrative fixture has no risk score or source
facts and is never served as an accepted case. A normal sign-in shell is available
after build; working historical views require authorized registered artifacts.
